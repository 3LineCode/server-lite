# pyline 迁移收尾执行计划（依据 docs/migration-plan.md，已批准）

## 执行纪律（贯穿全程）
- 严格按里程碑 M1→M6 顺序推进；每个 F 编号独立走完「实现 → 测试 → 验证（`uv run ruff check` + `uv run mypy src` + `uv run pytest` 全绿）→ 提交（`fix(F-xx): ...` / `feat(F-xx): ...`）」闭环后才开始下一项。
- 里程碑完成时跑一次全量门禁确认无回归。
- 集成测试（`@pytest.mark.mysql/redis`）：执行时先探测本机 3306/6379 可达性，可达则本地跑，不可达则以 `-m "not mysql and not redis"` 跑其余并留待 CI 容器验证。
- 不新增任何运行时第三方依赖；griffe（stub 生成）仅入 dev 依赖组。
- 会话上下文接近用尽时，在当前 F 编号闭环后收尾并汇报进度与剩余项。

## M1 数据安全（F-01..F-11，先行）
- **F-01/F-02** `db/autosave.py` 重构：删除 max_attempts 丢弃路径；失败改指数退避（`cooldown×2^(n-1)`，上限 300s）由 `_deferred` 时间戳驱动重试；in-flight 集合消灭关停取消窗口；`flush_all` 改带总时限（默认 60s）的循环重试，超时逐 saver CRITICAL 日志 + 非零退出；失败/深度告警回调。测试 4 项（retry_keeps_dirty / shutdown_flush_retries / shutdown_deadline_reports_loss / stop_drains_inflight）。
- **F-03/F-04** `db/orm.py`：`load()` 改 async + in-flight future single-flight（并发 50 调用只发 1 条 SQL）；`delete()` 先 SQL 后置 DELETED、失败状态不变、幂等。测试 3 项。
- **F-05** `db/schema.py` + `runtime.py`：`ensure_database()` 用无库连接先 `CREATE DATABASE IF NOT EXISTS ... utf8mb4` 再建池（修首启必炸）。测试：test_schema_creates_database_first（mysql 标记）。
- **F-06** `db/schema.py`：`pyline_schema` 单行版本表（Alembic 模式）+ `migrations/NNN_name.sql` 顺序应用 + `information_schema.COLUMNS` 声明漂移检测（只报错不 ALTER）；DDL 显式 `ALGORITHM=INSTANT, LOCK=NONE` 不满足即失败。测试 3 项（mysql 标记）。
- **F-07** `db/orm.py`+`serialization.py`：解码路径接线 `peek_version` → 当前版本直读 / 旧版本走 `loads_migrated` / 更新版本抛 `BlobVersionError`。测试 2 项。
- **F-08** 新增 `pyline/tools/migrate_pickle.py`：受限 pickle（白名单类型）→ msgpack 转换 CLI，默认 dry-run，`--execute` 生效，往返校验。测试 1 项。
- **F-09** `config/models.py`+`db/schema.py`：`isolation_level` 改 `Literal` 白名单；表/列 COMMENT 统一转义；`TableFieldDef` 补 `unique/default/not_null` 字段。
- **F-10** `db/mysql.py`：keepalive 改池外专用连接（miss_limit 次失败→告警→关停）；任务异常 done-callback 记录；`_configured_conns` 改 `WeakSet`。
- **F-11** `db/redis.py`：官方参数 `socket_timeout/socket_connect_timeout/health_check_interval`；清理 decode 死分支。

## M2 网络健壮（F-12..F-18）
- **F-12** `net/protocol.py`+`connection.py`：删除 `@` 前缀分块豁免（修 >1MB RPC 静默损坏）；`max_frame_size` 配置接入 `FrameDecoder`；flag 非 UTF-8 抛 `ProtocolError`；重组总量校验。
- **F-13** 分发隔离：`connection.py` 读循环 `safe_dispatch`（应用异常只丢帧不断链）+ `rpc.py` 消息 arity 校验 + 畸形帧速率超限断连；TCP/ZMQ/proxy 三路统一。
- **F-14** `rpc.py`：pending 先注册后 send（路由失败立即清 pending）；结果打包失败回发错误帧（消灭假超时）。
- **F-18** `rpc.py`：超时/取消向远端补发 MSG_CANCEL。
- **F-15** `net/ipc.py`：单写者模型 + 每对端有界队列（消灭 ROUTER 头阻塞与乱序），保留一个版本的 `ipc_legacy` 开关。
- **F-16** `net/proxy.py`+`models.py`：重连循环整体守护 + IDENT 核验（IP↔machine 号一致 + 重复声明拒绝）+ `inter_token` 双 token + 客户端来源拒绝内部 RPC 面。
- **F-17** `connection.py`：close 冲刷在途消息 + `wait_closed`；服务端主动 ping 空闲探测；`@welcome` 握手确认。

## M3 内核（F-19..F-28）
- **F-19** `core/lifecycle.py`：启动任务异常进 `stuck_error` fail-fast；`run_boot` 门循环检查 QUIT（修启动期关停挂死）；二次信号强杀。
- **F-20** `runtime.py`：主进程 `loop.add_signal_handler`；teardown 每步 try/except + finally 链 + 总时限。
- **F-21** `core/supervisor.py`：join 异步轮询化；task 强引用统一取消；补全套测试（现状零覆盖）。
- **F-22** `log/`：文件 channel 注册表移入 Context（修模块级缓存）。
- **F-23** `core/scheduler.py`：close 取消短定时器句柄；协程回调持引用+异常记录；`interval<=0` 抛错；强制 `bind_loop`。
- **F-24** `core/events.py`：子类多态分发（MRO 缓存）；泛型收紧；新增 `EnvReadyEvent`。
- **F-25** `core/clock.py`+`runtime.py`：时区显式配置（zoneinfo）；边界 tick 补发错过的整点；`week_day`→`week_no` 修正；编号基数保持旧仓兼容并文档化。
- **F-26** `config/loader.py`+`secrets.py`+`context.py`：数字键重复检测；secrets 路径声明式收集；未知 process_type 抛错；`$plain:` 空值语义修正。
- **F-27** `devtools/console.py`+`runtime.py`：console 仅主进程；`￥` 前缀；时钟事件写 clock.log。
- **F-28** `obs/metrics.py`：全部定义指标接线埋点；主进程 `start_http_server`；告警回调接口 + 四个内置告警源。

## M4 热更防护（F-29/F-30）
- **F-29** `reload/inplace.py`：沙箱去执行化（纯 AST 静态检查，消灭副作用双跑）；`inspect.signature` 向后兼容校验（新参数必须带默认值）；单次读源共用字节码（消灭 TOCTOU）；类字典快照真回滚；`__eq__/__hash__/__slots__` dunder 守卫；属性级 `__reloadkeep__`；新属性 `__reload_default__` 回填旧实例；`docs/hot-reload.rst` 禁忌清单。测试 6 项。
- **F-30** `net/gateway.py`：注册表热更钩子（活实例重绑 handler）。

## M5 业务门面 + 模板
- 新增 `pyline.api` 包（env/registry/task/timer/rpc/db/redis/orm/clock/debug/coverage/log 薄层门面，Context 注入，mypy strict），语义逐条对齐旧仓 aioapi（见方案 4.1 映射表）。
- `TrackedDict/TrackedList` 容器（变更自动 touch）。
- `template/game/com_time.py`（逐函数移植，编号基数/锚点不变）+ `containers.py`（TimeData/DayData/WeekData/DataOP，TimeUpset bug 修正）。
- coverage.py 官方 API 集成；structlog banner + 启动完成地址打印；griffe stub 生成脚本（dev 依赖）。

## M6 测试/CI/文档收尾
- CI 集成 job 实质化（mysql/redis 标记测试真正跑起来）；覆盖率门禁 65→85（core/net/db/reload ≥90）；mkdocs 文档站 + 旧→新 API 迁移对照表；CHANGELOG + v1.0-RC。

## 验收基准
全程以三道门禁为准：`uv run ruff check src tests`、`uv run mypy src`、`uv run pytest`（含新增约 60+ 用例）零失败；每项修复带方案中规定的验收测试名。
